What Easy Connect does

Easy Connect is a standalone communication app with independent SSH and FTP tabs. It uses Dropbear for SSH and vsftpd for FTP, running with the launching reader account’s permissions. It does not require CoolReader or replace the firmware’s system accounts.

This development build has limited PB632 testing: anonymous FTP and SSH commands/basic shell access have been confirmed, and the updated app was confirmed working after the Home/reopen fix. Full scanner, suspend and USB lifecycle acceptance testing remains incomplete. Other models and firmware are unverified.

Install Easy Connect over USB

  1. Press Exit in Easy Connect before updating. Home and the task switcher can leave its process running. Connect the reader by USB and select PC/storage mode.
  2. For an upgrade, back up system/share/easy-connect. Its state folder contains your password verifiers and SSH host key.
  3. Download the install ZIP Updated 24 October 2026 and extract it on your computer. Merge its applications and system folders into the root of the reader’s storage. Do not copy the enclosing ZIP folder.
  4. The bundle contains only the launcher, five executables and easy-connect.conf.default. Existing easy-connect.conf and state are preserved. Source code and notices belong on the computer, not on the reader.
  5. Safely eject the reader. Connect to Wi-Fi in the device settings, then open Applications → EasyConnect.
  6. Choose SSH or FTP. On a fresh install, press Start to set that service’s password. Enter at least 12 characters twice, then press Start again. SSH and FTP use separate passwords.

Factory defaults select password access for both services; no shared password or anonymous login is enabled. Settings save automatically, and saved settings take precedence over factory defaults. The IP address is checked every second. Service/settings controls enable when an address appears; tabs, Refresh Library, Exit and Save diagnostics remain clickable offline.

Keep Easy Connect in the foreground while connected. Closing or backgrounding it normally stops both services; connections are preserved while Refresh Library temporarily opens the firmware scanner. Stop a running service before changing its settings.

Connect to the PocketBook over SSH

Start SSH in the app, then use the username and IP address shown on the screen. The default username on the tested PB632 is reader, and the default port is 2222.

ssh -T -p 2222 reader@DEVICE_IP '/bin/sh -i'

Replace DEVICE_IP with the reader’s address. Compare the SSH fingerprint with the fingerprint shown on the device before accepting a new host key. Enter the SSH password configured in Easy Connect. Type exit to disconnect.

-T skips PTY allocation, which normal firmware launches may deny. /bin/sh -i provides a prompt over ordinary pipes. The message can't access tty; job control turned off is expected in this mode. Basic commands work; job control and full-screen terminal programs require PTY access. A plain ssh -T connection may work without displaying a prompt.

To run one command:

ssh -T -p 2222 reader@DEVICE_IP 'id; pwd'

For public-key authentication, select Public key or Key or password, then copy your public .pub key into system/share/easy-connect/state/authorized_keys over USB. Keep the private key on your computer. SFTP and SCP are not included.

Transfer files over Wi-Fi with FTP

Start FTP in the app and open an FTP client that supports uploads. Use the device IP, port 2121, the username shown on the FTP tab, and the separate FTP password. Choose plain FTP with passive transfers.

ftp://reader@DEVICE_IP:2121/

The starting folder is /mnt/ext1. Passive data ports default to 50000–50009. Upload, download, rename, delete and directory creation use the reader account’s filesystem permissions.

macOS Finder mounts FTP as read-only. Use an FTP client with upload support to modify files. A read-only Finder connection does not mean the server has disabled writes.

Optional No password mode accepts anonymous or ftp without an application password. It also permits file changes wherever the reader account has permission. Switch back to Password to require your saved FTP password.

Refresh the PocketBook Library

After adding, renaming or deleting books over FTP or SSH, tap Refresh Library at the bottom of either tab. The button also works without Wi-Fi. It asks the firmware to rescan the books; open Library when the app reports completion.

SSH and FTP may stay running, including active transfers. Connections remain active while the scanner temporarily takes the screen. A file still uploading may need another refresh after the upload finishes. Refreshing does not reset the Library database or erase reading history.

The button shows Refreshing... while scanning. Errors and the two-minute timeout are reported on screen; retain system/share/easy-connect/library-scan.log if reporting a scanner problem.

Security and compatibility limits

  • FTP is unencrypted. Passwords and file contents travel in plain text. This build does not support FTPS.
  • Anonymous FTP is open to reachable clients. They can read and change files allowed by the reader account.
  • The FTP starting folder is not a jail. Normal-user FTP clients can navigate outside it within that account’s permissions.
  • SSH is encrypted, but file-transfer subsystems are absent. SFTP and SCP are not included in this build.
  • Persistent state is stored on USB-visible storage. Anyone with USB access can read or replace password verifiers and host keys.
  • Wi-Fi loss, suspend, USB transitions and firmware Library scanning still need full device acceptance testing. Other models and firmware are unverified.

Troubleshooting and diagnostics

  • No IP address: connect to Wi-Fi in the reader settings and return to the app. Detection refreshes automatically every second; no Refresh button is needed.
  • Old or frozen UI after an upgrade: safely eject USB and fully power the reader off and on, then reopen Easy Connect. Home does not terminate the old process. Before future upgrades, use Exit.
  • Books missing or stale in Library: use Refresh Library; if an upload was still running, refresh again after it completes.
  • Password not set: press Start in that tab or use Set password. The app creates the verifier after confirmation; do not copy empty credential files.
  • SSH appears idle: use the interactive command above, or type id and press Enter. A pipe shell can be connected without a visible prompt.
  • FTP appears read-only in Finder: use a client with FTP upload support.
  • App or service fails: tap Save diagnostics, reconnect USB, and retain system/share/easy-connect/diagnostics.txt and ui.log. Include the model, exact firmware version and steps in a GitHub issue. Do not share passwords, private keys or password verifier files.

Upgrade or remove Easy Connect

For an upgrade, press Exit before connecting USB, then merge the new install ZIP over the existing files. Your saved settings, passwords and host key remain. If the app was running during an update, safely eject and fully power the reader off and on so it loads the installed executable. To remove everything, close the app, connect USB, and delete applications/EasyConnect.app and system/share/easy-connect. This also removes its credentials and logs. It does not remove CoolReader or your books.
