Installation

  1. Connect the reader by USB. Close CoolReader and back up your existing files and settings.
  2. Extract the ZIP. Merge system and applications into the reader’s storage, keeping existing files.
  3. Safely eject the reader. Open Applications → CoolReader.

To add CoolReader to Library’s “Open with” menu, follow the file-association instructions in the guide.

About this build

R5 fixes a language-symbol collision that caused a crash while drawing the first page. It includes the earlier startup fixes and an Applications shortcut.

Confirmed on device
Book display and physical page buttons.
Still to verify
Touch gestures, dictionary, sleep/wake, frontlight, and saved reading position.

Only PB632 with firmware 6.11.2001 has been verified.
