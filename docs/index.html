Installation

  1. Connect the reader by USB. Close CoolReader and back up your existing files and settings.
  2. Extract the ZIP. Merge system and applications into the reader’s storage, keeping existing files.
  3. Safely eject the reader. Open Applications → CoolReader.

To add CoolReader to Library’s “Open with” menu, follow the file-association instructions in the guide.
