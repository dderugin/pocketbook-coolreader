Reading

CoolReader for PocketBook

Read EPUB, FB2 and other supported book formats with configurable typography, bookmarks and reading history. This build updates CoolReader for Touch HD 3 firmware 6.11.2001.

Wireless access

Easy Connect: SSH and FTP for PocketBook

Transfer books and files over Wi-Fi with vsftpd, or run shell commands through Dropbear SSH. Start and stop SSH and FTP independently, then refresh the PocketBook Library after adding or removing books. Easy Connect is a standalone app; CoolReader is not required.

Easy Connect

Installation & connection guideSHA-256 Updated 24 October 2026GitHub source
  1. For an upgrade, press Exit in Easy Connect first. Extract the ZIP and merge applications and system into USB storage.
  2. Safely eject, connect the reader to Wi-Fi, then open Applications → EasyConnect.
  3. Press Start to set a service password, then press Start again to run it.

Updated app confirmed working on PB632 after the Home/reopen fix. See what changed and the Refresh Library guide. Development build with limited device acceptance testing. FTP is unencrypted; anonymous access is optional and allows file changes. FTPS, SFTP and SCP are not included. Read the security and compatibility notes before connecting.

Device compatibility

These builds target PocketBook Touch HD 3 / PB632 and firmware U632.6.11.2001. Other models, including Verse Pro and InkPad 4, are unverified. Check each tool’s guide for validation limits and troubleshooting.
