PocketBook tools website
=======================

Primary website: https://pocketbook.nimbushub.eu/
CoolReader and Easy Connect are independent tools in this collection.
The old coolreader.nimbushub.eu domain redirects to the new domain, preserving paths.
nginx serves all pages and downloads directly; no application server is required.

Website files
-------------
index.html, installation.html, easy-connect.html, styles.css, assets/favicon.svg,
LICENSE.txt, release.json, easy-connect-release.json, robots.txt and sitemap.xml.
No JavaScript, external fonts, tracking or API keys are needed.

Preview locally
---------------
From docs/, run: python3 -m http.server 8080 --bind 127.0.0.1
Open http://127.0.0.1:8080/. Downloads must be staged in downloads/ for local testing.

Publication
-----------
See deploy/nginx/README.md for routing, publication, HTTPS renewal and validation.
The internal document root remains /var/www/coolreader/current for continuity.
Publish into a new release directory and atomically switch that symlink.
Always preserve both tools' downloads when updating either tool.
Keep private keys and build workspaces out of the web root.

Permanent downloads
-------------------
/downloads/coolreader-touch-hd3-latest.zip
/downloads/coolreader-touch-hd3-latest.zip.sha256
/downloads/coolreader-touch-hd3-source-latest.tar.gz
/downloads/easy-connect-pb632-latest.zip
/downloads/easy-connect-pb632-latest.zip.sha256
/downloads/easy-connect-pb632-sources-latest.zip
/downloads/easy-connect-pb632-sources-latest.zip.sha256
/downloads/easy-connect-README-latest.md

Copy matching source and notices alongside each binary. Easy Connect's install
ZIP contains only seven runtime files; sources and notices stay in its separate
companion archive. No GitHub release is required for website publication.
release.json describes CoolReader; easy-connect-release.json describes Easy Connect.
Record the actual source state and verification limits, not assumed test results.
Regenerate checksum sidecars and SHA256SUMS.txt using the deployed stable names.
Verify HTTPS, all local links, artifact hashes and HTTP Range responses before
removing superseded release directories.
