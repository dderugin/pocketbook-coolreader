CoolReader download website
==========================

This is a self-contained static website. No build, package manager, database,
external fonts, tracking, or API keys are needed. Binary and source downloads are hosted as versioned GitHub release assets.

Preview locally
---------------
From this folder, run:
  python3 -m http.server 8080 --bind 127.0.0.1
Open http://127.0.0.1:8080 in a browser.

You can also open index.html directly. No JavaScript is required.

Publish
-------
Copy this folder's contents to any static web host or web server document root.
Keep index.html at the root, and preserve assets/ paths.
The site uses relative URLs so it also works in a subdirectory.
Use HTTPS for a secure download connection.
Serve .zip as application/zip, .gz as application/gzip and .txt as text/plain.
Large binary/source downloads are served by GitHub Releases rather than Pages.
There are no secrets or SSH access tools in this website.

Contents
--------
index.html       Download, compatibility and installation steps
styles.css       Minimal responsive design
assets/          SVG favicon
Downloads        Versioned links to GitHub release assets
release.json     Public release metadata
LICENSE.txt      CoolReader's GPL v2 license
