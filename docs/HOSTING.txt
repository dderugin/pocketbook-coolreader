CoolReader download website
==========================

Primary website: https://coolreader.nimbushub.eu/
The page and every release download are served directly by nginx.
No Kubernetes resources or application server are required.

Website files
-------------
index.html, styles.css, assets/favicon.svg, LICENSE.txt and release.json
Downloads are served from /downloads/ on the same domain. The artifact URLs
are absolute so the GitHub Pages mirror also points to the self-hosted files.
No JavaScript, build process, external fonts, tracking or API keys are needed.

Preview locally
---------------
From docs/, run:
  python3 -m http.server 8080 --bind 127.0.0.1
Open http://127.0.0.1:8080. Downloads use the primary website.

Deployment
----------
See deploy/nginx/README.md in the repository for configuration, publication,
TLS renewal, validation and rollback instructions.
The nginx document root is /var/www/coolreader/current, a symlink to a release
folder under /var/www/coolreader/releases/.
Private keys remain in the server's /etc/letsencrypt directory.

including the install ZIP, corresponding source, patch, debug symbols,
